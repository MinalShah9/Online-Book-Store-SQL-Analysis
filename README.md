# 📚 Online Book Store SQL Analysis

SQL-based analysis of an Online Book Store database using **MySQL and SQL** to derive sales, customer, and inventory insights.

---

## 📌 Project Overview

This project analyzes an Online Book Store database using **MySQL and SQL**.

The database contains three main tables:

- 📚 Books
- 👥 Customers
- 🛒 Orders

The objective is to analyze book sales, customer behavior, revenue, genres, authors, and inventory using SQL queries.

📊 Key Business Areas

📚 Book Performance :
Analyze books, genres, prices, and sales.

💰 Revenue Analysis :
Calculate total revenue and identify high-value orders.

👥 Customer Analysis :
Identify frequent and high-spending customers.

✍️ Author Analysis :
Analyze the total quantity of books sold by each author.

📦 Inventory Analysis :
Calculate available stock and remaining stock after orders.
